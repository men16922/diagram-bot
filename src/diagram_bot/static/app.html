      구성도 다운로드

      현재 환경의 최신 편집본을 다운로드합니다.
      화면 밖 도형도 포함해 구성도 전체가 출력됩니다.

      규격 내보내기는 이 보기를 고른 규격으로 새로 그린 구성도입니다. 이동·메모 같은 수동 편집은 들어가지 않으며, 편집본으로 저장되지 않습니다.

      수집 데이터
      IaC 초안

      수동 편집은 구성도 표현에만 적용됩니다. JSON·CSV는 수집 당시의 전체 리소스를, 검토 결과 CSV는 심각도·근거·권장 조치를 담습니다. CloudFormation은 같은 구성을 다시 만드는 템플릿 초안으로, AMI·인증서·IAM 역할은 매개변수로 두고 표현할 수 없는 항목은 Metadata.DiagramBot에 적습니다.
      MULTI-ACCOUNT

      계정 통합 보기

      계정·리전별 수집을 두 개 이상 고르면 하나의 연결도로 합칩니다. 공유된 Transit Gateway와 계정 간 피어링은 소유 계정의 리소스 하나로 이어집니다.
      DRAW.IO XML

      draw.io XML 가져오기 · 정렬 · 사내 표준

      이미 가진 draw.io 구성도를 스냅샷으로 가져오거나, 겹침을 고쳐 자동 정렬하거나, 회사 템플릿을 사내 표준으로 채택합니다. 라벨에서 읽은 내용은 추론이며 AWS API 근거가 아닙니다.

      사내 표준으로 채택

      템플릿에서 규격(래퍼·상자·스타일)을 추출하고, 정렬한 템플릿을 스냅샷으로 저장해 엽니다. 기본 규격으로 지정하면 표준이 서버에 저장되어 다운로드 규격 목록과 AI 어시스턴트에서 쓸 수 있습니다.
