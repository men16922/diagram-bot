# Diagram Bot 시연 가이드

AWS 인증 없이 실행할 수 있는 시연 버전입니다. 샘플은 계정 `111122223333`, 서울 리전, 두 VPC, 세 서브넷, EC2 세 개, ALB 한 개, 대상 그룹 한 개를 포함합니다. 일부 조회 실패를 의도적으로 넣어 실패 범위 표시도 확인할 수 있습니다.

## 준비

README의 설치 후 아래처럼 **새로운 데이터 디렉터리**로 실행합니다. 기존 저장본에 영향을 주지 않고 시연을 반복할 수 있습니다.

```bash
diagram-bot setup-editor
diagram-bot serve --data-dir reports/presentation-01
```

http://127.0.0.1:8765 를 데스크톱 Chrome/Chromium에서 열고 창을 1440×900 이상으로 설정합니다. 전체 화면을 넓게 보려면 1600×1100을 권장합니다. 앱 설치·편집기 설치는 시연 전에 완료하세요.

## 5분 시연

1. **환경 탐색:** 왼쪽의 두 VPC를 전환합니다. 샘플 배지, 계정·리전, 수집 시각을 보여줍니다. 첫 VPC는 두 AZ와 EC2, ALB·대상 그룹을 포함합니다.
2. **근거 확인:** `web-a`를 선택합니다. 오른쪽에서 인스턴스 유형, VPC, 서브넷, API 관계 근거를 확인합니다. ALB의 여러 서브넷 연결도 속성 패널에서 확인합니다.
3. **누락 범위 설명:** `부분 조회` 버튼을 눌러 EC2 `UnauthorizedOperation`과 부분 조회 상태를 보여줍니다. “조회 불가는 리소스 없음과 다르다”는 점을 설명합니다.
4. **검색·내역:** 리소스 목록에서 EC2만 선택하거나 `web-a`를 검색합니다. 참조 표시를 켜 SG·ENI·EBS가 상세 조회된 리소스와 구분됨을 확인합니다.
5. **draw.io 편집:** 참조 표시를 끄고 `＋ 메모`를 누릅니다. 추가된 메모를 더블클릭해 `검토 완료`로 바꿉니다. 도형을 드래그해 위치도 조정할 수 있습니다. `편집본 저장` 후 새로고침해 메모가 남는지 확인합니다.
6. **다운로드:** `다운로드`에서 `.drawio`와 2× PNG를 받습니다. PNG는 화면 밖 도형도 포함합니다. 1×·투명 배경으로도 출력합니다. `.drawio` 파일은 독립적인 draw.io 앱에서 다시 편집할 수 있습니다.
7. **데이터 재사용:** JSON·CSV를 다운로드합니다. JSON 가져오기로 새 스냅샷을 만들면 자동 생성 배치가 표시됩니다. 수동 메모는 원본 AWS 데이터에 추가되지 않습니다.

실제 AWS를 보여줄 때만 먼저 `aws sso login --profile 프로파일명`을 실행한 뒤, 앱에서 예상 계정 ID와 리전을 지정해 수집합니다. 실제 수집 시연은 해당 환경의 권한·접속을 사전에 확인해야 합니다.

## 저장과 복원

- 다른 VPC나 참조 표시로 이동하기 전에 현재 편집을 저장합니다. 각 보기의 편집본은 별도 보관됩니다.
- `자동 배치로 복원`은 API 스냅샷에서 배치를 다시 생성합니다. 저장하면 해당 보기의 기존 수동 배치를 대체합니다.
- 새로 수집하거나 JSON을 가져오면 새 스냅샷이 생깁니다. 기존 스냅샷과 편집본은 보존됩니다.
- 저장 충돌 메시지가 나오면 다른 창에서 저장한 상태를 새로고침해 불러옵니다.
- 수집 진행 상태는 메모리에 있으므로 실행 중 서버를 종료하면 진행 상태가 복원되지 않습니다. 완료된 스냅샷은 파일로 남습니다.

## 재현 가능한 브라우저 검증

```bash
pip install -e '.[test,browser]'
python -m playwright install chromium
diagram-bot serve --data-dir reports/browser-check-01
# 다른 터미널
python scripts/verify_demo.py
```

새 데이터 디렉터리를 사용해야 합니다. 검증 스크립트가 메모와 가져온 스냅샷을 추가하므로 실제 업무 데이터에 실행하지 마세요. 결과는 `artifacts/browser/verification.json`, 화면 캡처, draw.io 파일, 흰색/투명 PNG로 남습니다. 저장소에는 합성 샘플만 포함합니다.

검증된 항목: 선택·속성 연동, 조회 범위, 검색·종류 필터, VPC 전환, 참조 표시, 네이티브 메모 편집, 저장·다시 열기, `.drawio`, PNG 2× 흰색/1× 투명 배경, JSON·CSV, JSON 가져오기. 편집기에서 외부 HTTP 요청이나 JavaScript 예외가 발생하면 검증을 실패 처리합니다.

## 문제가 생기면

| 증상 | 확인 사항 |
| --- | --- |
| 편집기 설치 안내 | `diagram-bot setup-editor` 후 서버 재시작 |
| 포트 사용 중 | `diagram-bot serve --port 8766` 후 해당 주소 열기 |
| SSO 만료·권한 오류 | 터미널에서 SSO 로그인, 프로파일/계정/읽기 권한 확인 |
| PNG 생성 지연 | 1×로 낮추고 한 VPC만 선택해 출력 |
| 오래된 편집본 표시 | 자동 배치로 복원하거나 새로운 데이터 디렉터리 사용 |
