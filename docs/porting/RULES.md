# 포팅 규칙 (모든 에이전트)

- 경로: `docs/…`·`src/…`·`scripts/…` = Diagram Bot 체크아웃(`<DB>`, 읽기 전용). `<회사:…>` = 회사 저장소, 값은 프롬프트로 받는다.

## 읽기
- 카드 「읽을 것」만. 저장소 전체 탐색·검색 금지.
- `§` 지정 시 그 절만: `sed -n '/^## 절이름/,/^## /p' 파일`.
- 복사된 `diagram_bot/` 모듈 본문은 카드가 지정할 때만 연다. API는 카드 치트시트로.

## 쓰기
- 코드는 `scripts/port_copy.py`로만 복사(오케스트레이터가 실행). 직접 복사·재입력 금지.
- 복사된 `diagram_bot/` 수정 금지. 특히 `layout/` 좌표, `drawio_spec` 요청 규칙(`request_spec`). 회사 포맷은 `DrawioSpec`으로.
- 카드의 허용 파일 밖 변경 금지. push·배포 금지.

## 보안 경계
- HTTP로 받은 `spec`은 `drawio_spec.request_spec`만(프리셋 이름·객체, 경로 거부).
- XML 입력은 `read_document`를 거친다(`align_*`·`inspect_*`·`import_*`는 이미 거침).
- 서버는 요청 값으로 파일을 읽지 않는다. 경로는 서버 설정·CLI에서만.

## 명령
- 출력이 큰 명령(전체 테스트·빌드·pip) 금지 → 멈추고 오케스트레이터에 요청.
- 직접 돌리는 명령은 `2>&1 | tail -20`.

## 세션
- 세션당 컨텍스트 150K 토큰 상한(272K 할증 구간보다 훨씬 아래). 카드마다 새 세션.
- 120K 근처 또는 30턴: 멈추고 `결과: 이어서`로 보고. 새 세션은 그 보고 절만 받는다. 대화록 붙여넣기 금지.

## 멈춤
- 완료 조건 통과 → 바로 보고하고 멈춤.
- 멈추고 보고: 같은 실패 3회 / 턴·예산·컨텍스트 상한 / 허용 파일 밖 변경 필요 / 자격 증명 없음 / 제품 결정 필요 / `<회사:…>` 값 없음.

## 보고
회사 저장소 루트 `PORTING_LOG.md` 끝에 추가. 다음 세션은 「다음 카드에 넘길 것」만 읽는다.

```markdown
## <카드 id> · <모델> · 세션 <n>
- 결과: 완료 | 이어서 | 멈춤(<사유>)
- 턴 / 비용: <n> / $<추정>
- 완료 명령 꼬리: (≤15줄 코드 블록)
- 바꾼 파일: <경로>
- 남은 문제: <없음 | 목록>
### 다음 카드에 넘길 것
- <꼭 필요한 사실 ≤10줄>
- 다음: <카드 id>
```
